## Authentication

All API requests require Bearer token authentication.

<CodeGroup tabs="cURL,Python,JavaScript">
  ```bash
curl -H "Authorization: Bearer YOUR_API_KEY" https://api.tracktag.me/v1/tracks
  ```
  ```python
import requests

headers = {"Authorization": "Bearer YOUR_API_KEY"}
response = requests.get("https://api.tracktag.me/v1/tracks", headers=headers)
  ```
  ```javascript
const response = await fetch('https://api.tracktag.me/v1/tracks', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
});
  ```
</CodeGroup>

<Callout kind="info">Include the Authorization header in every request. API keys are available in your dashboard.</Callout>

## Response Format

All responses use JSON format with consistent structure.

<CodeGroup tabs="Success Response,Error Response">
  ```json
{
  "id": "track_123",
  "title": "Summer Nights",
  "artist": "DJ Cool",
  "bpm": 128,
  "key": "C Major",
  "genre": "House",
  "status": "completed"
}
  ```
  ```json
{
  "error": "Invalid file format",
  "code": "INVALID_FORMAT",
  "message": "Only MP3, WAV, and FLAC files are supported"
}
  ```
</CodeGroup>

## Error Handling

<Steps>
  <Step title="Check Status Codes" icon="alert-circle">
    Handle 4xx and 5xx responses appropriately.
  </Step>
  <Step title="Parse Error Messages" icon="message-square">
    Use error codes to determine retry strategies.
  </Step>
  <Step title="Implement Retries" icon="refresh-cw">
    Retry failed requests with exponential backoff.
  </Step>
</Steps>

<Expandable title="Common Error Codes" default-open="false">
  - `INVALID_FORMAT`: Unsupported file type
  - `FILE_TOO_LARGE`: Exceeds size limits
  - `RATE_LIMITED`: Too many requests
  - `UNAUTHORIZED`: Invalid API key
</Expandable>

## Rate Limiting

TrackTag enforces rate limits to ensure fair usage across all users.

| Plan | Requests/Minute |
|------|-----------------|
| Free | 10 |
| Pro | 100 |
| Enterprise | Unlimited |

<Callout kind="danger">Rate-limited requests receive 429 status codes. Monitor the X-RateLimit headers.</Callout>

<ExpandableGroup>
  <Expandable title="Rate Limit Headers" default-open="false">
    - `X-RateLimit-Limit`: Maximum requests per minute
    - `X-RateLimit-Remaining`: Remaining requests
    - `X-RateLimit-Reset`: Time until reset
  </Expandable>
  <Expandable title="Handling 429 Errors" default-open="false">
    Implement exponential backoff when receiving rate limit errors.
  </Expandable>
</ExpandableGroup>
