## Supported Formats

TrackTag accepts common audio formats without requiring format conversion:

- MP3 (all bitrates)
- WAV (uncompressed)
- FLAC (lossless)
- AAC, M4A
- OGG

<Callout kind="tip">For best results, upload high-quality source files. Our AI performs better with clearer audio.</Callout>

## API Upload

Use our REST API to upload files programmatically.

<CodeGroup tabs="cURL,Python">
  ```bash
curl -X POST \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@track.mp3" \
  https://api.tracktag.me/v1/uploads
  ```
  ```python
import requests

with open('track.mp3', 'rb') as f:
    response = requests.post(
        'https://api.tracktag.me/v1/uploads',
        headers={'Authorization': 'Bearer YOUR_API_KEY'},
        files={'file': f}
    )
  ```
</CodeGroup>

## File Size Limits

| Plan | Individual File | Batch Total |
|------|-----------------|-------------|
| Free | 50MB | 200MB |
| Pro | 100MB | 1GB |
| Enterprise | 500MB | 10GB |

<Expandable title="File Size Optimization" default-open="false">
  For large files, consider compressing temporarily or splitting long tracks into segments.
</Expandable>

<Callout kind="alert">Files exceeding size limits will be rejected. Check your plan limits before uploading.</Callout>

## Processing Time

Processing time depends on file length and complexity:

- Short tracks (< 3 minutes): 10-30 seconds
- Albums/full sets: 5-15 minutes
- Large batches: 30+ minutes
