## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added support for OGG and M4A file formats
- Improved BPM detection accuracy by 15%
- New batch processing queue with progress tracking

## Improvements

- Faster processing times for short audio files
- Enhanced error messages for failed uploads
- Updated dashboard with real-time processing status

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- Complete API redesign with RESTful endpoints
- Webhook support for processing notifications
- Advanced metadata extraction including musical key detection

## Breaking Changes

- API v1 endpoints are deprecated - migrate to v2
- Authentication now requires Bearer tokens
- Response format changes for metadata fields

</Update>

<Update label="2024-08-10" description="v1.5.0" tags={["feature", "bugfix"]}>

## New Features

- Initial release with core music tagging functionality
- Support for MP3, WAV, and FLAC formats
- Web-based upload interface

## Bug Fixes

- Fixed BPM calculation for tracks with varying tempo
- Resolved upload failures for large batch files
- Improved genre classification accuracy

</Update>
