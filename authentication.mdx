## API Authentication

To use the TrackTag API, you need to authenticate using API keys. This ensures secure access to your music processing requests and prevents unauthorized usage.

<Callout kind="info">Keep your API keys secure and never share them in public repositories or client-side code.</Callout>

## Getting Your API Key

<Steps>
  <Step title="Sign Up" icon="user">
    Create an account at tracktag.me and verify your email.
  </Step>
  <Step title="Generate Key" icon="key">
    Navigate to your dashboard and click "Generate API Key".
  </Step>
  <Step title="Copy Key" icon="copy">
    Copy the generated key and store it securely.
  </Step>
</Steps>

## Using API Keys

Include your API key in the Authorization header for all API requests.

<CodeGroup tabs="cURL,Python,JavaScript">
  ```bash
curl -H "Authorization: Bearer YOUR_API_KEY" https://api.tracktag.me/v1/tracks
  ```
  ```python
import requests

headers = {"Authorization": "Bearer YOUR_API_KEY"}
response = requests.get("https://api.tracktag.me/v1/tracks", headers=headers)
  ```
  ```javascript
const response = await fetch('https://api.tracktag.me/v1/tracks', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
});
  ```
</CodeGroup>

## Rate Limiting

TrackTag enforces rate limits to ensure fair usage:

| Plan | Requests/Minute | Requests/Hour |
|------|-----------------|----------------|
| Free | 10 | 100 |
| Pro | 100 | 1000 |
| Enterprise | Unlimited | Unlimited |

<Expandable title="Rate Limit Headers" default-open="false">
  Check the `X-RateLimit-Remaining` and `X-RateLimit-Reset` headers in responses to monitor your usage.
</Expandable>

<Callout kind="danger">Exceeding rate limits will result in 429 Too Many Requests responses. Upgrade your plan for higher limits.</Callout>

## Security Best Practices

- Store API keys as environment variables, not in code
- Use HTTPS for all API requests
- Rotate keys regularly
- Monitor your API usage in the dashboard

<ExpandableGroup>
  <Expandable title="Environment Variables" default-open="false">
    Set `TRACKTAG_API_KEY` in your environment and access it securely in your code.
  </Expandable>
  <Expandable title="Webhook Security" default-open="false">
    Verify webhook signatures to ensure requests come from TrackTag.
  </Expandable>
</ExpandableGroup>
