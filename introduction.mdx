## Getting Started

TrackTag is an AI-powered music metadata generation service that automatically tags your music files with accurate information like BPM, key, genre, and professional track names. This makes it ideal for DJs, producers, and anyone managing large music libraries.

## Use Cases

TrackTag serves various music professionals:

- **DJs**: Prepare tracks with accurate BPM and key information for seamless mixing
- **Producers**: Organize project files with consistent naming and metadata
- **Music Libraries**: Maintain large collections with automated cataloging
- **Podcasters**: Add professional metadata to audio content

<Expandable title="Supported File Formats" default-open="false">
  TrackTag supports MP3, WAV, FLAC, AAC, OGG, and M4A formats. Files up to 100MB can be processed individually, with batch uploads supporting up to 1GB total.
</Expandable>
